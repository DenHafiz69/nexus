# Nexus 🚀

Nexus is a powerful and lightweight multitool web application designed for efficiency. It currently features a robust **URL Shortener** and a **QR Code Generator**, built with a modern stack focusing on performance and simplicity.

## ✨ Features

-   **URL Shortener**: Transform long, cumbersome URLs into clean, manageable short links.
-   **QR Code Generator**: Generate high-quality QR codes for any text or URL instantly.
-   **Modern UI**: Clean, responsive interface powered by Tailwind CSS.
-   **Seamless Experience**: Fast, dynamic updates without full page reloads using HTMX.
-   **Containerized**: Easy deployment and development using Docker and Docker Compose.

## 🛠️ Tech Stack

-   **Backend**: [FastAPI](https://fastapi.tiangolo.com/) (Python)
-   **Database**: [PostgreSQL](https://www.postgresql.org/) with [SQLAlchemy](https://www.sqlalchemy.org/) ORM
-   **Frontend**: [Jinja2](https://jinja.palletsprojects.com/) Templates, [HTMX](https://htmx.org/), and [Tailwind CSS](https://tailwindcss.com/)
-   **Infrastructure**: [Docker](https://www.docker.com/) & [Docker Compose](https://docs.docker.com/compose/)
